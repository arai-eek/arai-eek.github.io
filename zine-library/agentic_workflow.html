Manifesto: Speculative Archiving

The Arai-eek Zine Library is a mycelial network of 80+ PDF variants spanning 20 years. To navigate this mass, we deployed a Human-Agentic Workflow—a synthesis of human curatorial intent and machine-scale narrative processing.

◈ THE "MADE UP" ADVISORY: The "Deep Info" research dossiers are speculative syntheses. When the agent encounters image-heavy PDFs with zero extractable text, it defaults to Style-Consistent Speculation. Using the zine title, folder metadata, and surrounding thematic clusters, the agent "hallucinates" a poetic narrative to guide the user through the visual chaos. This is an intentional archival strategy, not a factual transcript.

The .agent Cognitive Substrate

We formalized our collaborative session into a persistent machine-readable infrastructure. This project is not a static site, but a Stateful Archival System stored in the .agent folder.

  • ◈ Archive Logic (workflows/): A persistent skill definition that allows future agents to immediately understand how to ingest new PDFs (Scan -> Extract -> Synthesize -> Reconcile).
  • ◈ Build Engines (scripts/): Specialized Python engines (build_static_catalog.py, build_interactive_map.py) that map the deep_info.json source-of-truth into production assets.
  • ◈ Metabolic Persistence: The deep_info.json acts as the "Collective Memory" of the archive, ensuring that poetic Dossiers and thematic tags survive session truncations.
